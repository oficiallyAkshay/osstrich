# Classification — community, company, company-adjacent

Read BEFORE D2 classifies anything; append a row for every project not yet here. Definition: **company** = authored by a for-profit company; **company-adjacent** = authored by the community to make a for-profit company's product more accessible (an MCP server, an API wrapper, a client SDK, an account or subscription tool for a vendor's product); **community** = neither. Both non-community classes rank behind every community project — deferred, never removed. An **override** keeps a project eligible despite its class; it carries the maintainer's ruling and the date.

Every reason is a claim about an external fact; re-check the owner and purpose when a row is more than 90 days old.
